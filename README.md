# Matrix Manipulation

A web AI-based Matrix Calculator built using **Python, Flask, NumPy, HTML, CSS, and JavaScript**. The application allows users to perform common matrix operations on 2×2 matrices, including **addition, subtraction, multiplication, determinant calculation, and matrix inverse**.

The project uses a **Flask backend** to process matrix calculations with NumPy and a responsive frontend to collect inputs and display results dynamically. It also includes input validation, error handling, loading animations, and a modern animated user interface.

## Features

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Determinant Calculation
* Matrix Inverse
* Input Validation
* Error Handling
* Responsive and Animated UI
* Flask REST API integration

## Technologies Used

* **Python**
* **Flask**
* **NumPy**
* **HTML**
* **CSS**
* **JavaScript**
* **Flask-CORS**
